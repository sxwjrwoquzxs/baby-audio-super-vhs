## Overview

Baby Audio Super VHS transforms any signal with authentic lo-fi VHS tape character—adding flutter, warble, hiss, and frequency degradation for instant vintage atmosphere.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Baby Audio Super VHS** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Tape Warble** | Speed instability modeled after real VHS transport mechanics |
| **Frequency Degradation** | High-frequency rolloff and vinyl-style noise coloring |
| **Hiss and Hum** | Adjustable tape hiss and 50/60 Hz mains hum overlay |
| **Saturation** | Soft-knee saturation mimicking magnetic tape overload behavior |
